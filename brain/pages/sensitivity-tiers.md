## 三条正交的防线(2026-10-16 之后的口径)

2026-10-16 用户:「死区和按键时忽略手势组合起来还是有很多误触」⇒ 三条一起收紧,各管一段:

| 防线 | 管什么 | 现在的值 |
|---|---|---|
| 死区 | "手放在面上、还没打算划"的落点噪声 | 键盘表面 12dp(≈1.9mm);屏幕触摸板 8dp |
| 提交线(档位) | "真去划一页要划多远" | 键盘表面 12 / 24 / 60px(死区之外) |
| 静默窗 | "这一刻手在键上 / 刚离开键" | 按住键期间 + 抬手后 300ms(可配置) |

**别拿一条去够另一条**:死区不必去挡"按键抖动"("手在键上"是物理事实,归静默窗);
档位不必去挡"落点噪声"。这个分工是 2026-10-16 明确下来的。

## 静默窗:两段并集(原来只有"按键后 300ms"一段)

`KeyEventGate`。2026-10-02 用户给的 200ms → 2026-10-04 改 300 → **2026-10-16 扩成两段**:

- **按住键期间一律不接手势**;
- **抬手后 `blockMs` 内也挡**(默认 300;设置页 `PREF_KEY_GATE_MS` = 0 / 200 / 300 / 500)。

旧版只有后者,而且从 **DOWN** 起算 —— 按住不放时窗口早就过期,而那段恰恰是
"手指压在键上、表面还在报坐标"的时候(键面被固件映射成屏幕触摸,一次按键既产生 KeyEvent
也产生一条触点流)。**窗口从 UP 起算**由单测钉住。

- **挡掉的是整条手势**(不起拖动、不画位移),不是"跟完再弹回去" —— 后者读起来是延迟,
  用户会当成卡了再划一次。判定在手势起手那一下问一次,整条手势记住结论。
- **入口全查**:键盘表面(FlyDetector)/ 候选行 / L5 面板三条实际滑动入口,共用同一个 `swipeBlocked`;L4 也接了门,但当前不接横滑(预留)。
  点按与长按一律不查("敲一个键紧接着点候选上屏"是最常见手速)。
- **透传的键也记**(用户 2026-10-02「无论是否消费」)。
- 配对容错:DOWN 按 keyCode 记集合(自动重复不重复计数 —— 记数会让一次抬手消不掉);
  漏抬由 `HELD_STALE_MS` 5s(距最后一次键事件)兜底,窗口收起时另有 `onWindowHidden` → `reset`。
- **不豁免修饰键**:按住 Shift/Alt 再划也会被挡。用户原话是"按键 down 的时候就忽略手势",
  照字面执行、不设例外;代价是"按住修饰键 + 划键盘面"这条组合失效(已回报用户,待确认是否开口子)。
- **它不只是防误触,还是回弹的一个压制手段**:按键后候选正在换,窗口内划一下可能命中
  还没稳定的那一页,与下一次按键的时序叠加就会来回翻 ⇒ 遇到"反复回弹"时,除了弹簧参数
  还要查事件时序。**这一条与阻尼比无关,调 ζ 治不了它。**

## 死区:键盘表面单独一档 12dp(`DEAD_DP_SURFACE`)

`DragGesture.DEAD_DP_SURFACE = 12f`(≈1.9mm),键面的**上滑(飞字)与横滑(翻页)共用**。
屏幕上的候选行 / L5 面板仍是 `DEAD_DP` / `DEAD_DP_SWIPE` = **8dp**(≈1.3mm)——
那边没有"手按在键上"这回事,8dp 够用(2026-10-09 那条结论对屏幕触摸板仍然成立)。

**为什么键面要单独一档**:键面不是真触摸屏,落点由固件按 10 个键列映射到屏宽
(一列 ≈ 144px ≈ 9mm),压键那一下手指会滚一下,表面就报出可观的位移。
4dp(0.6mm)连生理性手抖(0.3~1mm)都盖不住 → 8dp 仍报误触 → 12dp。
经过与理由写在 `DragGesture.DEAD_DP_SURFACE` 的注释里。

**代价(2026-10-03 就此记过,仍然成立)**:每个消费者都要单独确认量纲 ——
`pageDragDeadPx` 在键盘面驱动时必须返回 0(基线定在"死区被跨过的那一帧")。

## 横滑档位第二列 ×3:4/8/20 → 12/24/60

口径是**死区之外**的提交距离(2026-10-02 定)。8px ≈ 0.5mm,指尖压键滚一下就过线,
等于"一碰就翻"。整列 ×3 之后,键面上真去翻一页要划 死区 30px + 提交线 ≈ 42 / 54 / 90px
(2.7 / 3.4 / 5.7mm;一个键列 ≈ 144px ≈ 9mm)。

**台阶形状是 2× / 2.5× ⇒ 放大只能整列放大**(`PageThresholdTierTest` 钉着倍差);
比例那一列(行宽 0.16 / 0.22 / 0.33)一个数没改 —— 那是候选行 / L5 的量纲。
