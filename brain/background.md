# Project background

为 Unihertz Titan 2 这类**物理全键盘 Android 手机**做一款以硬件键盘为第一公民的输入法，交互模型模仿「可可拼音输入法」（CocoIME），但针对 Titan 2 的系统限制重新设计可行的替代通道。

## 目标

- 物理键盘优先：绝大多数输入路径只需按键即可完成，屏幕只承担候选展示与手势。
- 中文拼音 + 英文两种输入态；候选框固定 5 个候选位。
- 三条核心手势/按键通道：**上滑选字**、**左右滑候选词翻页**、**Alt/Sym 双击锁定**。
- **Sym 锁定切换三层键盘**（基础字母层 / 符号数字层 / 编程开发层），第三层预置开发常用符号与功能键映射（`{}`、`[]`、`<>`、`: = -> => //` 等），并允许用户自定义每个键的输出。
- 词库可导入（自带中等词库，支持导入用户词库扩容）。

## 非目标（本期不做）

- 双拼、模糊音、繁体输出、语音输入、云候选、无障碍「快捷发送」。
- 针对非全键盘机型的软键盘体验优化（软键盘只作为兜底与手势载体）。

## 目标用户

全键盘手机重度用户，尤其是需要在手机上用 Termux / vim / ssh 干活的开发者——这也是模仿对象可可输入法作者的原始动机。
