# 常见问题

## 支持哪些手机？

**它是为 Titan 2 量身定做的。**

别的全键盘机型我们没测过。可能能用，也可能键位对不上，装在别的机器上出问题是预期之内。

## 怎么装上？

见「下载与安装」。一句话：下载安装包，允许安装，然后在系统设置里把它选成默认输入法。

## Titan 2 上有什么要改的？

把 Fn 键设成 Ctrl：设置 → 快捷键与手势（或键盘设置）→ Fn 键 → 选「Ctrl」。Alt、Sym、Shift 不用管。

## 五个候选怎么选？

首选占着空格位，其余四个按顺序分给 Shift、Sym、Ctrl、Alt。想选哪个，手指不用离开原来的位置。

也可以直接点，或者左右滑翻页。

## 怎么切中英文？

`Shift + 空格`。

## 怎么切层？

Alt 和 Sym 单击切一层、双击锁住、长按临时用。用哪种都行，按住的时候状态行会告诉你现在是哪一层。

## 怎么打分节符？

组词的时候按 `v`，比如 `xi'an` 只出「西安」，不会出「先」。

## 全拼打不出来怎么办？

打首字母。比如 `nh` 就是「你好」。

## 怎么让常用的词排前面？

用得多的词会自己往前挪。想清掉重来：设置 → 词库 → 清空用户词库。想备份：导出成文件。

## 它会收我的数据吗？

会收一点，用来改词库：你选了哪个词、它排第几位、哪个功能被多点、崩溃在哪一步。**不会**收你在输入框里打的完整内容、没上屏的草稿、别的应用里的事。

每台设备一个随机编号，不关联你的身份。设置里可以随时关掉，关掉后不再发送，已发的也一起删。

细节见「关于」，那里写得全一点。
