## 安装步骤

1. 下载上表的 `app-release.apk`。
2. 系统提示"未知来源"时，允许当前浏览器或文件管理器安装应用（按提示进 设置 → 应用 → 特殊权限 → 安装未知应用）。
3. 装好后进 **设置 → 语言和输入法 → 默认输入法**（部分系统在 设置 → 系统 → 语言和输入法），选中"盖亚输入法"。
4. 打开任意输入框，用右上角的键盘图标切到盖亚输入法。

首次切过去时会在后台加载词库，约 1–2 秒，之后就能正常拼音。

## 用 adb 装

```bash
adb install -r app-release.apk
```

`-r` 表示覆盖安装。两个包同签名，直接换包升级不会报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`。

## Titan 2 用户：把 Fn 键设为 Ctrl

五键选字里的 `Ctrl` 单击、以及 `Ctrl+C` 这类组合键都走系统 `Ctrl` 键位，需要先把 Titan 2 的 Fn 键指派给它：

**设置 → 快捷键与手势（或键盘设置）→ Fn 键 → 选「Ctrl」**。

`Alt` / `Sym` / `Shift` 不需要任何设置，装完直接可用。设置页首次打开时也会弹一次同样的提示。

## 系统要求

- Android 8.0 及以上（minSdk 26），targetSdk 34。
- 物理全键盘机型优先，为 Unihertz Titan 2 优化；其他全键盘机型多数也能用（L4/L5 的键位是运行时按本机键位表筛的）。
- 没有屏幕键盘的机型请在设置页打开"显示屏幕键盘"——它承载候选栏与手势。
