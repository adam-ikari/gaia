# 下载与安装

<Downloads />

## 装上

1. 下载上面的安装包。
2. 系统问起"允许安装未知应用"时，按提示放行当前浏览器或文件管理器。
3. 装好后打开 **设置 → 语言和输入法 → 默认输入法**（部分系统在 设置 → 系统 里），选中"盖亚输入法"。
4. 打开任意输入框，用右上角的键盘图标切过去。

第一次切过去要等一两秒，词库在后台加载。之后就是正常打字。

## 升级

直接装新的那个包就行，设置和词库都还在。

## Titan 2：把 Fn 键设成 Ctrl

五指选字里的 Ctrl、以及 `Ctrl+C` 这类组合，都走系统的 Ctrl 键位，需要先把 Fn 指派给它：

**设置 → 快捷键与手势（或键盘设置）→ Fn 键 → 选「Ctrl」**

Alt、Sym、Shift 不需要设置，装完直接可用。

## 什么机型适合

**专为 Unihertz Titan 2 做的。** 别家全键盘机型没测过，装了可能对不上。

只有屏幕键盘的机器不是它的场景，它假设你的手指一直待在键盘上。
