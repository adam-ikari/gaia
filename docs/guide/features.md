# 功能详解

## 三层键盘

盖亚把物理键盘分成三层，`Alt` / `Sym` 负责切换，L1–L3 对应 Titan 2 键帽上印的那三层：

| 层 | 键帽 | 内容 |
| --- | --- | --- |
| L1 | 字母 | 英文字母与常用标点 |
| L2 | 符号数字 | 数字、符号，印字按厂商键位表（TitanKey.kcm）对齐 |
| L3 | 编程 | 开发常用符号与功能键：`{}` `[]` `<>` `: =` `->` `=>` `//` 等 |

L3 每键的输出都可以在设置页里逐键改，键位表可导出成文本备份、也可导入回来。

## 修饰键：单击、双击、长按

同一个键按不同次数与时长，含义完全不同：

| 按法 | `Alt` / `Sym` | `Shift` |
| --- | --- | --- |
| 单击 | 切一层，用完回原层 | 大写一次 |
| 双击 | 锁定该层 | 锁定大写（Caps） |
| 长按 | 按住期间进层，松开取消 | 按住期间大写，松手取消 |

锁定状态在状态行上以一条下划线标出，一次性与按住态不加下划线。

**借层语义**：锁着 `Alt` 时再单击 `Sym`，是"借一层"——敲完回到锁定的 `Alt`；没锁定任何层时借一层，敲完回 L1。层切换判定统一在松手时完成，所以按住期间的显示与最终结果一致。

## 选字：五键与飞字

候选栏固定 5 个候选位，**首选居中**放在空格位上，其余按 `4 2 1 3 5` 排列：

| 物理键 | 对应候选 |
| --- | --- |
| `Shift` | 第 2 个 |
| `Sym` | 第 5 个 |
| `空格` | 第 1 个（首选） |
| `Ctrl` | 第 4 个 |
| `Alt` | 第 3 个 |

`Ctrl` 加字母的组合键原样转发给应用，不参与选字。

候选栏本身也支持点选、左右滑翻页、长按删除自造词。**飞字**是在键盘表面上滑：按区上滑选中，候选词随手指缓缓起升，越过阈值就飞进输入框，其余候选同步渐隐。

## 拼音：分节符与首字母

- **分节符走 `v` 键**：组词过程中按 `v` 即插入 `'`。分节符原样进引擎并按分节位约束匹配——`xi'an` 只中"西安"、不会中"先"；不带分节的歧义照旧按词频排序。
- **首字母检索**：全拼三路（精确、前缀、分段）都匹配不上时，改按音节首字母查，`sm` → 什么 / 生命 / 说明。

## 词库

内置约 34.8 万条词（词与词频来自 jieba 词表，读音由 pinyin-pro 在构建期离线生成）。用户词频采用饱和曲线加权：单次使用增量递减，不会因为手滑连按几次就把某个词顶到最前，也不会跨档。

设置页可以导入、导出、清空用户词库，也可以查看词库状态（内置条数、自造词条数、频次记录数）。

## 状态行与虚拟按键

48dp 紧凑单行，分两种状态：**组词时**整行显示候选，**空闲时**显示状态行。状态行分三区：

- **左区 · 状态**：语言（`拼` / `En`）恒显；层与大写状态**没触发就不出现**。这一区不触摸——切层、切中英、大写都走物理键。
- **中区 · L4 虚拟按键**：只放 L1–L3 敲不出来的键，随三件事变化——当前语言、当前输入法、当前输入框类型。
  - 网址框 → `http://` 之类；
  - 邮箱框 → 短域名后缀（`.com` `.net` `.org` `.cn` `.edu`）优先，完整域名靠后；
  - 数字类输入框 → 自动锁数字层，`0-9`、`-`、`.`、`+*#`、日期时间的 `-/:.` 按合法字符放行；出厂只有电话场景带 `+86 +1 +81 +44` 等国际区号。
  - 判定是**运行时**做的：按本机键位表三层输出的并集筛，换手机、换键位表自动跟随。
- **右区 · 按钮**：键盘图标（仅当 L4 有溢出时出现，点它切换 L5 行）、设置、收起，三颗都是 48dp 见方。

**L5 溢出行**：L4 一行装不下的键移到状态行上方的独立行，左侧对齐、键宽取自然宽。飞字阈值、上滑选字、翻页方向等都可以在设置页调。
