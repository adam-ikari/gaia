# 功能

## 打字

三层键盘，用 Alt 和 Sym 换层：

- 单击切一层，用完回原来那层；
- 双击锁住这一层，不用一直按着；
- 长按临时用，松手就回原来的层。

Shift 管大写：单击只大写下一个，双击一直大写，长按是按住期间一直大写。

## 选字

屏幕上固定五个候选，你最能用的那个排在正中间。

空格上屏。剩下四个按顺序分给 Shift、Sym、Ctrl、Alt，手不用挪就能选。想省事直接点也行，左右滑翻页。

## 上滑

按住候选往上拖，词跟着手指走，拖到位松手就上屏。左右滑动键盘，候选词就跟着翻页。

拖多远算够，可以在设置里调；调大一点就不容易误触，调小一点抬手就能选。

## 带撇的拼音和首字母

组词的时候按 `v` 打出撇：`xi'an` 只出「西安」，不会出「先」。

懒得记完整拼法就打首字母，`nh` 就是「你好」。

## 换个输入框

你切到不同的输入框，屏幕上那行键就跟着变：

- 网址框给你 `http://` 这类开头；
- 邮箱框给你常用后缀，`.com` `.net` `.cn` 这些先占位置；
- 数字框只留数字能打的那些键；
- 日期、电话各有各的。

只有物理键盘本身敲不出来的键才会出现在这行上，能直接按的不会重复占位。

## 词库

内置三十多万个词。用得多的会自己往前挪。设置里可以导入词库、导出成文件备份、清空重来。

## 状态

屏幕左下角告诉你现在是什么状态：中文还是英文、在哪一层、有没有大写。锁住的那一层下面会多一道横线。

右边的三个按钮：键盘图标切换屏幕键盘，齿轮进设置，三角收起来。只有一行放不下的时候，键盘图标才出现。

## 调试用的东西

设置里的实验场给你一个干净的输入框试手感；按键探测器能显示物理键的真实键值，也能把某个键设成 Sym 键。
