# 功能

## 打字

三层键盘，用 Alt 和 Sym 换层：

- 单击切一层，用完回原来那层；
- 双击锁住这一层，不用一直按着；
- 长按临时用，松手就回原来的层。

Shift 管大写：单击只大写下一个，双击一直大写，长按是按住期间一直大写。

## 选字

屏幕上固定五个候选，你最能用的那个排在正中间。

空格上屏。剩下四个分别在 Shift、Sym、Ctrl、Alt 上，手不用挪就能选。想省事直接点也行，左右划翻页。

## 在键盘上滑

在键盘表面上按住往上划，词跟着手指慢慢升起来。手不用离开键盘，就能把词选出来。

划过头松手才上屏，没划到头它就弹回来。

候选栏上划也一样能选，手感是连着的。

左右划是翻页，跟上滑不是一回事。

## 带撇的拼音和首字母

拼音里带撇的词，只出带撇的那一个：`xi'an` 出「西安」，不出「先」。

懒得记完整拼法就打首字母，`nh` 就是「你好」。

## 换个输入框

你切到不同的输入框，屏幕上那行键就跟着变：网址框出网址开头，邮箱框出邮箱后缀，数字框直接锁数字。

只有键盘本身敲不出来的键，才会挤进这行里占位置。

## 词库

内置 34.8 万个词。用得多的会自己往前挪。

## 状态

状态行告诉你现在是什么状态：中文还是英文、在哪一层、有没有大写。锁住的那一层会多一道横线。

右边的三个按钮：切键盘、进设置、收起来。

## 调试用的东西

设置里的实验场给你一个干净的输入框试手感。
