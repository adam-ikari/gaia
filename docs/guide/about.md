# 关于

## 这是什么

盖亚输入法是给 Unihertz Titan 2 量身定做的拼音输入法。Titan 2 的键盘有 Alt、Sym、Fn 这些别的手机没有的键，输入法就是照着这双手长出来的习惯设计的。

屏幕只负责显示候选和状态，打字、选字、翻页交给键盘和手指。别的机型没测过，装了可能对不上。

## 数据

想让它更顺手，得知道真实使用是什么样。所以我们收一点数据回来：选中的词、它当时排第几位、哪个功能被多点、崩溃发生在哪一步。这些拿去改词库、查毛病。

不收的是这些：输入框里正在打的完整内容、还没上屏的草稿、别的应用里发生了什么。

每台设备一个随机编号，跟你的手机号、账号、机器序列号都无关，也没法拿它去别处认你。设置里有个开关，关掉之后不再发送，之前发过的统计数据连同这个编号一起删掉。

发送在后台按天合并一次，量很小，不影响打字。
