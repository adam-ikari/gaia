# L4 状态行中区 / L5 面板「场景」tab

L4 是状态行中区；L5 是状态栏上方的浮层面板，它的第一个 tab「场景」装 L4 一行放不下的尾巴。两者共用同一份按键列表和同一套优先级，区别只在**装不装得下**。

出处：`keymap/KeyLayout.kt`（`L4Priority`、`L4Key`、`L4_CORE`、各 `L4_PROFILE_*`）、`strategy/ImeRegistry.kt`（`l4Keys`）、`strategy/Language.kt`（`l4Extras`、`coreKeys`）、`ime/L5Ui.kt`（场景 tab 分页）。

## 为什么要分两个家族

早先的口径是「L4 放 L1-L3 敲不出的键」。那句话把两件性质不同的事混成一件，后果是两种误判：以为「敲得出就不该上 L4」（于是连「一次上屏一段常用串」这种纯粹的省事也否掉了），以及以为「L4 只该放单字符」（于是把词组短语塞进固定键档，名不正言不顺）。

- **固定符号键**（只有 `FIXED` 一档）：单个符号，物理 L1-L3 真敲不出，状态行是唯一入口。出厂核心只有 `；` 和 `$`。数量就那么几个，任何输入框都得有（按 `FieldProfile.l4CoreKeys` 过滤合法值，数字类全非法 → 整档退场）。
- **词组短语**（`PHRASE_HOT` / `PHRASE` / `PHRASE_COLD` 三档）：一次按键上屏一段常用串。**图的是省事，不是字形** —— 物理键敲 `+86` 要三下、敲 `...` 要三下，状态行一下。`…` `——` `「」『』※` 都属于这一族。

跨两个家族唯一一条取舍规则是**去重**：一次物理键就能敲出、并不省操作的取值不上状态行。

## 优先级分档

**数字小 = 优先**，排在前面、留在 L4；行宽不够被推进场景 tab 的是数字大的。所以「优先级」不是显示上的花活，它**就是**「这把键留在 L4 还是进场景 tab」的判据。

| 档 | 值 | 内容 |
| --- | --- | --- |
| `FIXED` | 0 | 固定符号键：出厂核心 `；` `$`。任何输入框都排在最前、留在 L4（词组短语挤不掉它们） |
| `PHRASE_HOT` | 5 | 通用高频短语：`…` `——`（半角态 `...` `--`）。任何输入框都用得上，排在模式短语之前 |
| `PHRASE` | 10 | 模式短语 / 通用短语：`http://` `.com` `+86` `00:00:00`。也是键位文件 `[L4]` 段自定义键的默认档 |
| `PHRASE_COLD` | 15 | 冷门短语：`「」『』※`。同性质但很少用，排最末、行紧时先溢出去 |
| `USER` | 30 | 用户自己编辑录入的短语。**功能还没实现**，档位先占住，接上时排在 `PHRASE` 之后即可 |

`PHRASE_HOT` 排在 `PHRASE` 之前不是审美选择：排在之后时，拼音邮箱模式下 `...` / `--` 会被挤到场景 tab 末尾（用户 2026-09-30 报障）。

**优先级不进键位文件格式**。文件里是 `label=output`，排不出「哪一把更该留 L4」——那是输入法自己的判断，要改档位改语言策略那一侧。

## 长尾到此为止

比 `PHRASE_COLD` 更冷的一律不上状态行：CJK 括号的第三四层、制表符与序号、emoji，连同 `USER` 那档自定义短语，都留给将来的屏幕软键盘。理由是物理键盘的状态行**只有一行**：每多一把冷门键，行宽就少留给高频键与模式短语，而 L4 与场景 tab 的切分是**前缀切**（装不下的整段进场景 tab），挤掉的往往正是高频键。

换句话说：长尾不是「排在后面」，而是**不在这一行**。要它们时用软键盘，那才是网格。

## L4 与场景 tab 怎么切

状态行中区取**装得下的最高优先级前缀**（`ui/L4PanelView.onMeasure` 按「前缀最长标签宽」判装不装得下），剩下的尾巴交给 L5 面板的「场景」tab。

- 槽宽 = min(填充值, 72dp 封顶, 不低于最长标签宽)；键多时恰好铺满 = 两端对齐，键少时收窄居中。
- 键间距固定 4dp，不许被拉大。
- 场景 tab 与符号盘共用同一套 **16 列细网格**：单字符只占 1 格（约 38dp），`@hotmail.com` 这类长串
  按**内容估宽**（`ceil(半宽字符数 / 4)` 格，中文按 2 个半宽算）跨 2–3 格——所以不同长度的键真的不同宽，
  但左缘都落在同一套格线上（2026-10-20 用户「键位不需要一样的尺寸 对齐网格就可以」；更早是 8 大格，
  单字符也占 1/8 屏太宽、长串又被长度分档挤成同宽）。换行/分页都按格算；上下滑动 / ↑↓ 在 tab 内翻页，不跨 tab。
  不再给场景单独改列数——列数一变，tab 之间的键就对不齐了（2026-10-19 用户定「网格布局 + 最小网格 + 内容跨网格」）。
- **面板高度固定两行**（2026-10-20 用户「L5的高度固定两行 多的内容需要翻页」）：每个 tab 每页
  最多 `16 列 × 2 行` 格，装不下的翻页；内容不足两行也占两行（视图补空行），切 tab / 翻页高度不跳。
  出厂字符盘改为**先过滤（本框合法性 + L1-L3 去重）再统一按网格分页**——先分页再过滤会在被滤掉的
  位置留下空格。剪贴板每条一行，一页两行。
- **「格」由权重槽定义，水平 margin 必须画在槽内层**（2026-10-20 用户报「L5按键网格没对齐」）：
  外框只按 `span` 占权重、**不带水平 margin**；3dp 键距加在内层 TextView 的 `marginEnd` 上。
  margin 若加在外框，每行要扣的 margin 总数随该行键数 / 跨格组合变化，换算出的 1 格宽逐行不同 ⇒ 列错位；
  不满行补空槽时最后一排的键还会被撑宽。内层 margin 方案下，一个 `span=2` 的外框宽恰好等于
  相邻两个单格键 + 中间键距。
- 键盘图标**常驻**（不再「有溢出才出现」）；点它或 `Sym+Space` 开关整个 L5 面板（OFF↔L5）。
  **锁定 Sym 不算按下**：双击锁 Sym 后空格照常上屏，不开关面板（单击借用 / 长按仍触发）。
- **没有可显示键的 tab 整个隐藏**：没有溢出时不再有「场景」tab（也不再画「(无溢出键)」占位键），
  剪贴板为空、或密码/数字类过滤后没有合法键的 tab 同样隐藏。

## 出厂核心键与合法性

核心键随输入框类型变化，规则是「合法的留、非法的去」：

| 输入框 | 核心键 | 依据 |
| --- | --- | --- |
| 默认 | `；` `$` | 全留 |
| 网址 | `；` `$` | 都是合法 sub-delim（`?a=1;b=2`） |
| 邮箱 | `$` | RFC 5322 的 atext 集合含 `$`（`user$tag@example.com` 合法），`;` 不在 |
| 数字类 | 无 | 固定键在该框全非法，`l4CoreKeys = emptyList()` |

L5 面板的文本键也走同一把「合法的留、非法的去」尺：密码框只留可打印 ASCII，数字/电话框只留数字与该类型放行的字符（`FieldProfile.digitChars`），整串都合法才保留（电话的 `+86` 留下，`@gmail.com`、中文标点滤掉）。此外，字符盘与 L4 共用 `ImeRegistry.producible`：**L1-L3 当前语言 + 全角开关下已经能敲出的单字不再重复摆**（2026-10-19 用户「L5 不需要 L1-L3 已经有的字符」）；面板开着切全/半会原地重算字符盘。场景 tab 已由 L4 同一条去重筛过，剪贴板是整段文本快捷入口、不按单字符再筛。功能键不是字符，不参与过滤；滤完没有键的 tab 隐藏。面板不设「控制」tab（2026-10-19 用户定案），Tab/Esc/Enter 等由物理键或 L3 承担。

核心键**整把交给语言处置**（`Language.coreKeys`：可换键帽与输出、可退场），而且必须在去重**之前**——核心键会同时出现在 `FieldProfile.l4CoreKeys` 和 `KeyLayout.l4Combined` 里，处置晚了同一把会以两个不同身份各留一把。

`；` 的键帽画的是全角，但实际显示/输出哪一把由 `Language.l4Replace` 按语言换：拼音态全角 `；`、英文态半角 `;`。换的是整把键（标签+输出），两边键帽都不骗人。

`\` 2026-09-29 已从固定键删除 —— 出厂 L3 的 `Sym+Z` 就能敲出它，按去重筛自动带走。组合按键 `-> => != ==` 也在 2026-09-28 移除：组合串要去就去 L3 或键位文件 `[L4]` 段自写，状态行中区只留单字符标点。

## 各输入框的出厂键位套

键位套**本身不含核心键**（并入哪些由 `FieldProfile.l4CoreKeys` 定）。套内按常用度排序——前几把留在 L4，装不下的尾巴进 L5 面板的「场景」tab。

### 网址 `[L4 url]`

`http://` `https://` `www.` `localhost` `127.0.0.1` `192.168.` `.com` `.cn` `.net` `.org` `.io` `.dev` `.app` `.co` `index.html` `.html` `.php` `.json` `.xml` `.js` `.css` `.htm`

不放 `/` —— 那是 L2 的键帽（`Alt+O`），L4 不重复。`?` `&` `=` 同理都在 L2/L3 上，会被去重筛带走。

### 邮箱 `[L4 email]`

短后缀在前：`.com` `.net` `.org` `.cn` `.edu`

完整域名在后：`@163.com` `@qq.com` `@126.com` `@gmail.com` `@hotmail.com` `@outlook.com` `@yahoo.com` `@icloud.com` `@foxmail.com` `@live.com`

「后缀占 L4、域名溢出场景 tab」由**键序 + 既有溢出规则**自然达成，不做硬分栏。

### 数字类 `[L4 number]` `[L4 signed]` `[L4 decimal]` `[L4 signeddecimal]`

出厂全空。这些输入框的合法字符全在 L2，**没有任何 L1-L3 按不出的东西可放** —— 不是被筛空的结果。数字框里能敲的就是数字与那几个符号，硬凑「短语」只会摆出输入框根本不收的东西。

数字类要 L4 有内容就得放**多字符组合**（物理键一次只出一个单字符，组合天然按不出），在对应段里自写。

### 电话 `[L4 phone]`

国际区号，按从国内拨出的常用度排：`+86` `+852` `+886` `+1` `+81` `+44` `+65` `+60` `+82` `+66` `+63` `+84` `+62` `+7` `+49` `+33` `+61` `+971`

只放区号不放分机符号：`,`（分机号分隔）归 `Sym+Z`，各家表单对 `转` / `ext` 的写法不统一，写死在键帽上容易连着后面的分机一起上屏。

### 日期时间 `[L4 datetime]`

`00:00` `00:00:00` `T00:00:00` `23:59:59`

时刻是数字类里唯一「单字符都按得出、整串仍然常用」的那一类 —— `:` 和数字在 L2 上都有键，可 `00:00:00` 这种整串按不出，所以天生属于 L4。

年月日不给 `2026-01-01` 这种：年份每月都变，写死在键帽上很快过期，而敲四个数字并不麻烦。

## 三轴决定用哪一套

L4 随三件事变化，见 [[ime-strategy-registry]]：当前**语言**（拼音 / 英文，补差键与全角符号不同）、当前**输入法**、当前**输入框类型**（选哪套键位套 + 核心键子集）。

## 编辑

设置 → 按键与层。`[L4]` 段自定义键默认落 `PHRASE` 档；`[L4 xxx]` 段可整段改写任何套。优先级档位在键位文件里写不出来，改档位改语言策略那一侧。

标签里的 `\` 与 `=` 在文件里要转义（`label=output` 按第一个 `=` 分割），核心键删不掉。
