<h2>每页五个，空格上屏。</h2>
<p>第一个词占住正中间，空格就是它；另外四个分别在 Shift、Sym、Ctrl、Alt 上。在键盘上往上滑也能上屏。</p>
</div>

::: band
<div class="gaia-band-inner gaia-band-narrow">
<h2>候选不止一页，往左往右划就翻页。</h2>
<p>整页跟着手指走。动画没停就再划一下，会直接转过去。</p>
</div>
:::

::: band
<div class="gaia-band-inner gaia-band-narrow">
<h2>动画是算出来的。</h2>
<p>弹簧动画按当前位置和手指速度算剩下那段要走多久，不是一条预先画好的曲线。手指划得快还是慢，收尾都不一样。</p>
<p>你在哪儿松手，它就补剩下的那一段，不会一闪而过。到位那一下很干脆；没选中、滑回去的时候也不晃。</p>
</div>
:::

::: band
<div class="gaia-band-inner gaia-band-narrow">
<h2>键盘分三层。</h2>
<p>字母、符号、编程。Alt 和 Sym 换层：按一下用一次，双击锁住，连按三次在三层之间轮着切。</p>
<p>Titan 2 没有独立数字行，符号得换层才打得出。</p>
</div>
:::

::: band
<div class="gaia-band-inner gaia-band-narrow">
<h2>输入框不同，中间那排跟着换。</h2>
<p>网址框里换成网址开头的键，邮箱框换成 @ 和常用后缀；数字框里，数字直接锁上。</p>
</div>
:::

::: band
<div class="gaia-band-inner gaia-band-narrow">
<h2>内置 34.8 万个词。</h2>
<p>用得多的词会往前挪。懒得打全拼就敲首字母：nh 就是「你好」。</p>
</div>
:::

::: band
<div class="gaia-band-inner gaia-band-narrow">
<h2>排序交给 Rime。</h2>
<p>输入引擎换成了 Rime —— 一个开源的中文输入引擎，装在应用里。哪个词更常用、你更常用哪几个，都由它排；打得多，那几个就排上来。</p>
</div>
:::

::: band
<div class="gaia-band-inner gaia-band-narrow">
<h2>快慢有三档。</h2>
<p>上滑选字要滑多远、左右划要划多远，都有三档：灵敏、标准、保守。觉得划页的方向别扭，可以反过来。震动也能关掉。</p>
</div>
:::

::: band
<div class="gaia-band-inner gaia-band-narrow">
<h2>只为 Titan 2 做的。</h2>
<p>别的全键盘机型没测过，键位可能对不上。系统的输入法随时能切回来。</p>
</div>
