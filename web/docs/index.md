<h2>每页五个，空格上屏。</h2>
<p>第一个词占住正中间，空格就是它；另外四个分别在 Shift、Sym、Ctrl、Alt 上。在键盘上往上滑也能上屏。</p>
<p>Ctrl 那一格靠的是键盘上的 Fn 键，得先在系统设置里把它改成 Ctrl。</p>

<h2>跟手。</h2>
<p>翻页时整页跟着手指走。滑到一半也能中断，退回原来那页，不会一下跳回去 —— 收回来那一段是从当前位置接着算的，不是重新播一遍。</p>
</div>
:::

::: band white
<div class="gaia-band-inner gaia-band-split">
<div class="gaia-band-copy">
<h2>往上滑，也算选词。</h2>
<p>屏幕下面那一行按横向切成五份。手指落在哪一份，选的就是那一个词；往上划多少决定的是<strong>划到哪儿才算数</strong>，不是划到哪一格。</p>
<p>划到位就立刻上屏，不用等抬手。不想用这个也可以点。</p>
</div>
<div class="gaia-band-visual">
<ZoneStrip />
</div>
</div>

<div class="gaia-band-inner gaia-band-narrow">
<h2>快慢有三档。</h2>
<p>上滑选字要划多远、左右翻页要划多远，各有三档：灵敏、标准、保守。用方向键翻页时，方向也可以反过来。震动也能关掉。</p>
<p>还有一档是给「刚按完物理键」的：那一下之后的一小会儿里，滑动不算滑动，免得按完键顺手一带就多选了字。</p>
</div>
:::

<div class="gaia-band-inner gaia-band-narrow">
<h2>键盘分三层。</h2>
<p>字母、符号数字、编程。Alt 和 Sym 换层：按一下用一次，双击锁住，锁着再敲一下就解开。</p>
<p>Titan 2 没有独立数字行，符号得换层才打得出。中英切换按 Shift 加空格，锁着哪一层都管用。</p>
<Shot src="crop-07-alt-layer.png" alt="状态行：左边依次是 拼、全、alt，alt 下面有一道下划线；中间一排是这一层能按出来的符号键；右边是设置和收起。" />
</div>
:::

<div class="gaia-band-inner gaia-band-narrow gaia-band-wide">
<h2>Alt 层照键帽印的。</h2>
<p>按住 Alt 再按键帽上的字母，打出来的是键帽侧面那一列符号。这一层是照着 Titan 2 出厂丝印排的，键帽上印的是什么，这里就是什么。</p>
<KeyCapMap layer="L2" note="大字 = 按住 Alt 时这把键打出来的东西；小字 = 键帽上印的字母。这是键位表，不是屏幕截图。" />
</div>
:::

::: band ink
<div class="gaia-band-inner gaia-band-narrow gaia-band-wide">
<h2>Sym 层我们自己排。</h2>
<p>这一层是编程符号，没有键帽可照抄，由我们定。成对的括号有意挨着排：<code>&lt;</code> <code>&gt;</code>、<code>[</code> <code>]</code>、<code>{</code> <code>}</code> 各占相邻两格。</p>
<p>中文全角时，其中十几格换成中文习惯的写法：<code>￥</code>、<code>《》</code>、<code>【】</code>、<code>、</code>。方向键、Esc、Tab、翻页这些位置不动。</p>
<KeyCapMap layer="L3" note="大字 = 按住 Sym 时这把键打出来的东西；小字 = 键帽上印的字母。这一层是输入法自己排的。" />
</div>
:::

::: band white
<div class="gaia-band-inner gaia-band-narrow">
<h2>框不一样，键不一样。</h2>
<p>网址框里换成网址开头的键，邮箱框里换成 .com、@qq.com 这些常用的结尾；数字框里，数字直接锁上。</p>
<p>电话框给的是数字加 <code>+</code> <code>-</code> 这些；日期时间框给 <code>-</code> <code>:</code> 和一串零。哪一类框该给什么，出厂就带着，不用配。</p>
<Shot src="crop-05-url-field.png" alt="网址框聚焦时的状态行：左边是 拼、全，中间一排依次是 ; … -- http:// https:// www.，右边是键盘图标、设置和收起。" />
<Shot src="crop-06-number-field.png" alt="数字框聚焦时的状态行：左边那一项写着 0-9，下面有一道下划线，表示这一层锁住了。" />

<h2>排序交给 Rime。</h2>
<p>输入引擎换成了 Rime —— 一个开源的中文输入引擎，装在应用里。哪个词更常用、你更常用哪几个，都由它排；打得多，那几个就排上来。</p>
</div>
:::

::: band white
<div class="gaia-band-inner gaia-band-narrow">
<h2>词库在包里。</h2>
<p>随包带着三万八千多个词、六万七千多条读法。一个词有几种读法就收几条。</p>
<p>懒得打全拼就敲首字母：<code>nh</code> 就是「你好」。拼音串会自动按音节分开，看得到自己打成了什么。</p>
<Shot src="crop-02-composing.png" alt="组词中的候选行：整行横排几格，正中间那格是首选，字比别处亮。" />
</div>
:::

::: band ink
<div class="gaia-band-inner gaia-band-narrow">
<h2>按住空格说话。</h2>
<p>没在打字的时候，长按空格说一句话，松手字就上屏。说的过程中，键盘上方那排小格跟着声音起伏。</p>
<p>识别在手机里完成，不用注册账号，也不用填什么密钥。只认中文。</p>
<p>这个开关默认关着，要在设置里打开并同意使用麦克风；密码框和纯数字框里不会启动。</p>
<p>语音模型跟着应用一起装（下载包约 170MB），所以比之前的版本大不少。</p>
</div>
:::

<h2>设置里能改。</h2>
<p>输入法的配色七套；字母键长按可以直接出这一层的符号；中文态的符号层可以出全角。</p>
<p>打得久了，常用的词会排上来。想退回出厂的样子，把学习记录清掉就行。</p>

<h2>装它之前。</h2>
<p>Android 8.0 及以上，只给 Unihertz Titan 2 做过。</p>
<p>包比一般输入法大，因为语音模型跟着一起装。</p>
<p>下载旁边那行有文件大小和校验值。这个网络下下载会静默截断，而安装器只回一句「软件包无效」—— 对一下那两个数，才知道是没下全还是包本身有问题。</p>
</div>
:::

::: band ink
<div class="gaia-band-inner gaia-band-narrow">
<h2>怎么装。</h2>
<p>一、装应用。系统会问要不要允许这个来源，允许。</p>
<p>二、打开系统设置里的语言和输入法，找到盖亚输入法，启用它并选为当前输入法。</p>
<p>三、把 Fn 键指派给 Ctrl。设置 → 快捷键与手势（部分系统版本叫键盘设置）→ Fn 键 → 选 Ctrl。不这么做的话，五个词里有一个键位是空的。Alt、Sym、Shift 不用设，直接可用。</p>
</div>
:::

<p>别的全键盘机型没测过，键位可能对不上。系统的输入法随时能切回来。</p>
